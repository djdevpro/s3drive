# @ud/ui

React 19 design system of S3 Drive: `--ud-*` tokens and 10 light/dark theme collections, shadcn-style
primitives on Radix, and drive components (file icons, quota meter, upload panel, app rail, theme picker,
settings panel, account menu). Router-agnostic; translations in 7 languages via `addUdUiResources(i18n)`.

```tsx
import '@ud/ui/styles/index.css';
import { Button, QuotaMeter } from '@ud/ui';
```
